The funniest one-line apology from an office printer (103 characters): it jammed again, but the paper was so cheap it apologised to the printer first — so the printer ate it out of pity. A tiny program (`main.ts`) writes the line into `/output/entry.txt` for make.fun's "The Printer Apology" bounty.

## Run it

```sh
node main.ts
```
